# 건축 공간분석 연구 프로젝트

## 소개
본 프로젝트는 건축 및 도시공간 분석을 위한 오픈소스 연구 프로젝트입니다.

건축 이론 연구와 디지털 설계 기술을 결합하여 공간 구조와 사용자 경험을 정량적으로 분석하고, 연구 결과를 재현 가능한 형태로 공유하는 것을 목표로 합니다.

특히 Space Syntax 기반 공간분석, DepthmapX를 활용한 공간 네트워크 분석, Grasshopper 기반 파라메트릭 설계 연구를 중심으로 건축과 도시환경의 관계를 탐구합니다.

또한 학생, 연구자 및 실무자가 활용할 수 있는 연구 자료와 분석 방법론을 공개하여 건축 연구의 접근성과 재현성을 높이고자 합니다.

## 주요 기능
- 건축 연구
1. 건축 이론 조사 및 문헌 정리
2. 국내외 건축 사례 분석
3. 공간구성 및 동선 연구
4. 도시환경과 건축의 관계 분석
5. 연구 결과 문서화

- 공간 분석
1. Space Syntax 기반 공간 구조 분석
2. DepthmapX 활용 통합도 및 연결도 분석
3. 보행 네트워크 및 접근성 분석
4. 건축 공간의 가시성 연구

- 디지털 설계
1. Grasshopper 기반 파라메트릭 모델링
2. 설계 프로세스 자동화
3. 데이터 기반 디자인 연구
4. 건축 및 도시 데이터 시각화

- 오픈소스 협업
1. 연구 자료 공개 및 공유
2. 분석 워크플로우 문서화
3. 버전 관리 및 연구 기록 관리
4. 재현 가능한 연구 환경 구축

## 사용 방법
1. 프로젝트 저장소를 클론합니다.
2. 연구 주제에 맞는 자료를 수집합니다.
3. 건축 사례를 분석하고 데이터를 정리합니다.
4. DepthmapX를 활용하여 공간 네트워크를 분석합니다.
5. Grasshopper를 활용하여 설계 및 시뮬레이션을 수행합니다.
6. 분석 결과를 문서화합니다.
7. 연구 결과를 공유하고 개선합니다.
